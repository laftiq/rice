# Проверки снимка

Выполнено в исходной среде Debian 13:

- Проверка синтаксиса всех Python- и shell-скриптов без запуска GUI.
- Разбор rc.xml, menu.xml и сохранённых XML; 34 сочетания клавиатуры и 55 действий мыши извлечены в документацию.
- Проверка наличия всех файлов snapshot-manifest.json и статических локальных ссылок в шаблонах.
- Поиск известных форматов секретов GitHub/Telegram/private keys и URL со встроенными токенами. Совпадений в экспортируемых файлах не найдено. Это не математическая гарантия отсутствия произвольной секретной строки; экспорт строился по разрешённым путям, а не копированием всей домашней папки.
- `apt-get --simulate install` для curated Debian-пакетов — без установки/изменения программ в текущей системе.
- Установка в отдельную временную домашнюю папку: подстановка пути, наличие скриптов и ресурсов; dry-run ничего не пишет; откат возвращает существующие файлы и удаляет новые; посторонние файлы сохраняются; изменённые после установки файлы защищены; выходящий за домашнюю папку симлинк отклоняется.
- Из сохранённого `vendor/i3lock` успешно скомпилирован тестовый бинарник GCC с уже имевшимися локальными dev-заголовками и текущими runtime-библиотеками; `--version` показывает `2.15-rice`. Блокировка активной сессии не запускалась.

В `.github/workflows/validate.yml` подготовлена отдельная сборка через Meson/Ninja в контейнере Debian 13. До создания репозитория и первого запуска CI это остаётся подготовленной, а не выполненной проверкой чистой сборки.

Ограничения: не проводилась полная переустановка компьютера, не менялась активная Openbox-сессия, не импортировались аккаунты, не проверялся ввод пароля на другом компьютере, не тестировались чистые Arch/Fedora. Внешние клиенты Happ/Яндекс Музыка/Telegram могут менять пути и D-Bus API между версиями.

После реального восстановления в Openbox:

```bash
rice-check-startup
```

Этот скрипт проверяет службы и локальные UI-зависимости. Дополнительный `--exercise` не является пассивной проверкой: он повторно вызывает инициализаторы и проверяет восстановление виджетов. Использовать его осознанно после входа.
