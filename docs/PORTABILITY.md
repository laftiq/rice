# Перенос и зависимости

## Debian 13

`packages/debian.txt` — минимальный тематический список, а не весь список программ исходного компьютера. `docs/debian13-tested-versions.tsv` фиксирует версии компонентов снимка. Установка свежих обновлений безопасности не блокируется точными pin-версиями.

Для проверки: `sh scripts/install-packages.sh --dry-run`. Для установки: `sh scripts/install-packages.sh --apply`. Скрипт не добавляет сторонних APT-репозиториев. Графическая сессия не запускается автоматически.

При минимальной установке убедись, что NetworkManager и звуковая сессия PipeWire/WirePlumber доступны. На исходном компьютере работают PipeWire и pipewire-pulse; pulseaudio-utils нужен для pactl, отдельный сервер PulseAudio не устанавливается. Существующие аудио- и сетевые службы установщик не перенастраивает.

## Другие системы

Установщик файлов написан на Python 3.9+ (для актуальных версий рекомендуются 3.12/3.13); большинство UI-скриптов используют Python 3, PyQt6, PyGObject/GTK3 и Pillow. Нужны X11, Openbox, Polybar, Rofi 1.7+, Kitty, Dunst 1.12-совместимый dunstctl, xss-lock/i3lock, pactl, playerctl, NetworkManager/nmcli, util-linux/udisks2/GIO. Для ctypes нужны системные X11, Cairo, librsvg, GObject и библиотеки клавиатуры. Для рабочего Bluetooth понадобится BlueZ; новый компьютер спаривается со своими устройствами отдельно.

- Ubuntu и другие Debian-производные: сначала проверь APT-список; отдельные версии/названия пакетов и наличие fastfetch/Qt6 могут отличаться.
- Arch: установи те же программы через pacman, а Python-модули через python-pyqt6, python-gobject, python-pillow; имена библиотек для сборки обычно идут без `-dev`. Этот путь документирован, но чистая установка на Arch не проверена.
- Fedora: установи те же компоненты через dnf и соответствующие `-devel` пакеты. Имена PyQt6/PyGObject различаются по релизам; сверь наличие через пакетный менеджер.
- NixOS: эти файлы не являются Nix-модулем. Абсолютные /usr/bin-пути в исходных desktop-скриптах потребуют adaptation/patching; автоматическую идентичность не обещаем.
- Wayland: Openbox, XQueryPointer, xprop, xrandr, scrot и i3lock предполагают X11. Это не конфигурация Sway/Hyprland.

## Изменения для переносимости

1. `/home/laptos` преобразован в `__RICE_HOME__` и подставляется новым установщиком. Имена брендов/окон/тем не переименованы.
2. Firefox helper больше не привязан к имени исходного профиля: профиль выбирается явно, сохраняются только CSS и тематические user.js-ключи.
3. Скрипт блокировки сохраняет исходный путь локальной сборки, но умеет использовать системный i3lock при `--skip-lock-build`.
4. rice-backup/rice-restore заменены на действующие переносимые реализации, поскольку исходные обёртки ссылались на отсутствующие backup.sh/restore.sh. Старые состояния/архивы не публикуются.
5. Не копируются скомпилированный i3lock, машинные .deb, уже отрисованный фон дисплея и файлы ready/log/lock. Бинарник и фон строятся из сохранённых исходников и logo.png.
6. Локальная копия курсора Adwaita побайтно совпала с системной. Она восстанавливается пакетом adwaita-icon-theme, а не дублированием 15 МБ системных ресурсов.
7. Не устанавливаются автозапуски, которых не было в сохранённом Openbox autostart. Например, app-layouts сохранён, но не включается дополнительно; sxhkd не запускается параллельно Openbox.

## Устройство и дисплей

Сохранён режим DP-1/1920×1080/144 Гц, но apply-display.py применяет его только при наличии соответствующего режима. На ноутбуке/другом разъёме отредактируй ~/.config/rice/display.json; неподдерживаемая конфигурация не принуждается. Отключение ускорения мыши использует XInput/libinput, не трогает touchpad/tablet и не меняет чувствительность.
