# laptos-rice

Графитовый Openbox/X11-райс с Debian 13: Polybar, Rofi, Kitty, Dunst, собственные меню и виджеты, скриншотер, буфер обмена, переключатель окон и изменённый i3lock. Снимок от **4 ноября 2026**.

Это восстановление оформления **и взаимодействий**, а не образ диска. Сохранены исходники всех обнаруженных пользовательских компонентов и статические ресурсы. Личные аккаунты и история не включены.

## Установка с нуля на Debian 13

Установи Debian 13 с X11 (без рабочего окружения тоже подходит). Из TTY или существующей сессии:

```bash
sudo apt update
sudo apt install git python3
git clone https://github.com/laftiq/rice.git
cd rice
sh scripts/install-packages.sh --dry-run
sh scripts/install-packages.sh --apply
python3 scripts/validate.py
python3 install.py --dry-run --with-session --with-shell
python3 install.py --apply --with-session --with-shell
```

Установщик запускай **обычным пользователем**, не через sudo. Только установка системных пакетов использует sudo. Закрой btop и cava перед применением: при выходе они записывают свой старый конфиг поверх нового.

После установки выйди из графической сессии и выбери **Openbox** в менеджере входа. Если менеджера входа нет, запусти `startx` из локальной TTY. Инсталлятор не выбирает дисплейный менеджер, не перезапускает рабочий стол, не меняет пароль, драйверы, PAM или сетевые подключения.

Полная визуальная копия экрана блокировки собирается из `vendor/i3lock`. Дистрибутивный пакет `i3lock` обеспечивает системную PAM-конфигурацию; бинарник с оформлением устанавливается только в `~/.local/libexec/i3lock`. Не заменяем `/usr/bin/i3lock` и `/etc/pam.d/i3lock`.

Если инструменты сборки недоступны:

```bash
python3 install.py --apply --with-session --with-shell --skip-lock-build
```

В этом случае используется установленный системный i3lock: блокировка сохраняется, но внешний вид поля пароля отличается.

## Откат и новые локальные копии

Каждая установка создаёт пофайловую резервную копию в `~/.local/state/laptos-rice/backups/<дата>/`, даже если установка прервётся.

```bash
rice-restore                         # перечислить копии
rice-restore ПУТЬ_К_КОПИИ            # предварительный просмотр
rice-restore ПУТЬ_К_КОПИИ --apply    # восстановить
rice-backup                          # приватный локальный архив текущего райса
```

Изменённые после установки файлы по умолчанию не перезаписываются при откате. `--force` разрешает восстановить и их. Откат не удаляет пакеты и не затрагивает файлы вне манифеста.

## После первого входа

```bash
rice-check-startup
fastfetch
btop
cava
```

Сверь настройки монитора: `~/.config/rice/display.json` хранит исходные DP-1, 1920×1080, 144 Гц. Скрипт применяет их только если такой режим действительно доступен; иначе сохраняет текущий режим. При необходимости отредактируй JSON под монитор.

В исходной конфигурации музыка и VPN отображаются через установленный Яндекс Музыка/Happ. Их программы и вход в аккаунты на новом компьютере устанавливаются отдельно. Графитовые стили Telegram/Аюграм лежат в `~/.config/rice/telegram` и `~/.config/rice/ayugram` и выбираются внутри клиента.

## Границы совместимости

Основа — X11, не Wayland. На других дистрибутивах переносимы конфиги, Python-код и исходники блокировки, но названия пакетов, пути бинарников, версии библиотек и приложения могут отличаться. Автоматическая установка пакетов проверяется для Debian 13; остальные системы описаны как ручной перенос, без обещания полной идентичности.

Исходный i3lock и темы сохраняют права и лицензии своих авторов: см. `THIRD-PARTY.md`. Скриншот полной личной сессии не публикуется, поскольку он содержит личные окна и вкладки.
